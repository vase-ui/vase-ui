A range with no text, for NVDA and JAWS

This page measures whether a screen reader says the name of a range that has no text in it. It uses native elements and no code of the library. Each range has an aria-label. The first range of each pair has only an empty element in it. The second has a text node too.

Procedure

  1. Open this file in a browser on Windows.
  2. Start the screen reader.
  3. Move to each range with the down arrow key in the browse mode of the screen reader.
  4. Write what the screen reader says in the table of results.
  5. Do the procedure for NVDA with Chrome, NVDA with Firefox and JAWS with Chrome.
