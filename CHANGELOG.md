# Changelog

## 2026.11.0

Matches Base UI 1.9.0. Includes later Base UI changes through `315eba7a` (2026-11-13).

### Breaking changes

- Raise the lowest supported version of Vue to 3.5.12. ([#81](https://github.com/vase-ui/vase-ui/pull/81))
- Use ECMAScript private members in the popup handle. The private members of a handle are not own properties. A method of a handle throws a `TypeError` on a proxy that is not from Vue. ([#382](https://github.com/vase-ui/vase-ui/pull/382))
- List only the change reasons that Range Calendar emits. `RangeCalendar.Root.ChangeEventReason` has no `month-press`, `year-press` or `trigger-press`. ([#541](https://github.com/vase-ui/vase-ui/pull/541))
- Time Clock: `TimeClock.Root.ChangeEventReason` has no `trigger-press`. The details of `viewChange` have their own type, `TimeClock.Root.ViewChangeEventDetails`. ([#549](https://github.com/vase-ui/vase-ui/pull/549))
- Give each part the server's attribute values in one hydration step. In the render before the mount of a hydration, a `#render` slot can get the server value of an `aria-*`, `role`, `data-*` or `abbr` attribute, as a string. ([#576](https://github.com/vase-ui/vase-ui/pull/576))
