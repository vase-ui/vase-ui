# Security policy

## Supported versions

Only the newest release of `@vase-ui/vue` gets security corrections. A correction ships in a new release.

## How to report a security problem

Do not report a security problem in public. Use [GitHub's private vulnerability reporting](https://github.com/vase-ui/vase-ui/security/advisories/new).

In the report, give the version of `@vase-ui/vue` and the steps that show the problem. Say what an attacker can do with it.

Vase UI is a port of Base UI. If Base UI has the same problem, report it to Base UI too. See [the security policy of Base UI](https://github.com/mui/base-ui/security/policy).

## What we do with a report

1. We answer in the report. The report stays private until we publish a security advisory.
2. With your help, we confirm the problem and find the versions that have it.
3. We correct the problem in private and publish a release with the correction.
4. Before we publish the security advisory, we remove the details that you do not want in public. We publish it on GitHub. It names that release and gives you credit if you accept it.

If a report does not show a security problem, we close it and give the reason.
